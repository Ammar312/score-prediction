# 🎯 Student Score Prediction using Scikit-learn

## 📌 Project Overview

This is a beginner Machine Learning project built using Python and Scikit-learn. The goal of this project is to predict a student's score based on the number of hours they studied.

This project helped me understand the basic workflow of a Machine Learning model, from preparing the data to making predictions.

## 🚀 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## 📂 Project Workflow

1. Load the dataset.
2. Explore and understand the data.
3. Prepare the data for training.
4. Split the dataset into training and testing sets.
5. Train a Linear Regression model.
6. Make predictions on the test data.
7. Visualize the results.
8. Evaluate the model.

## 📊 Features

* Data loading and preprocessing
* Data visualization using Matplotlib
* Linear Regression model
* Score prediction
* Model evaluation

## ▶️ How to Run

1. Clone this repository.
2. Install the required libraries:

   ```
   pip install pandas numpy matplotlib scikit-learn
   ```
3. Open the Jupyter Notebook.
4. Run all the cells.
